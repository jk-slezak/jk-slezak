#### Featured project

**[Grunberg](https://github.com/jk-slezak/Grunberg)**: a browser-based text RPG dungeon crawler · [play the demo](https://grunberg-game.vercel.app)

React 19 UI built with atomic design and CSS Modules, on top of a pure TypeScript game engine with unit and property-based tests. A Fastify API is the source of truth: it validates player intents with Zod and stores game state in Postgres (Drizzle) with optimistic locking. Monorepo, CI/CD to Vercel.

`React` `TypeScript` `Vite` `Fastify` `PostgreSQL` `Vitest`
